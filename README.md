📊 Superstore End-to-End Data Analysis Project

This project presents a complete end-to-end analysis of the Superstore dataset using Python (Colab), Excel, and Power BI.
It includes data cleaning, exploratory data analysis (EDA), Excel pivot analysis, visualizations, KPI calculations, and an interactive dashboard.

Tools & Technologies

Python (Pandas, Matplotlib, Seaborn)
Google Colab
Excel (Pivot Tables, Power Query)
Power BI (DAX, Visualizations)
GitHub (version control)

Project Structure
/data – raw_data.xlsx, cleaned_data.xlsx
/python_notebook – superstore_analysis.ipynb
/excel – Superstore_Pivots.xlsx
/powerbi – Superstore_Dashboard.pbix
/images – dashboard_preview.png, charts.png
